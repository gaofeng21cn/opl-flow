# Terminal Readback

After any Flow mutation, read the owner-authoritative surfaces that apply:

1. Flow package identity, installed carrier bytes, enabled exposure, and
   executor callability.
2. `package_operational`, `experience_baseline`, and
   `specialized_capabilities` as separate results.
3. Effective Profile status and target hash/backup/apply receipt when changed.
4. Model mode, explicit override, resolved model, reasoning effort, and policy
   source without claiming unavailable catalog entries are usable.
5. Requested Skill IDs from fresh executor discovery; each core Skill must have
   one source owner.
6. For Ledger: Beads/Dolt pull/push or explicit no-change parity.
7. For `start`: Dashboard, exact `codex://thread/` Bead link, one active hourly
   heartbeat, complete Linear mapping, duplicate counts zero, and validated
   onboarding receipt.
8. For Fleet: explicit Instance root, fresh node admission, repository
   currentness, lease/runner receipt, and sanitized private-state boundary.

Report missing external authorization or a required new session as remaining
work. Do not present a dry-run, test, candidate branch, merge packet, stale
projection, or Automation prompt as terminal state.
